# 🚀 Laboratorios de Arquitectura N-Capas con Spring Boot

¡Bienvenido a este repositorio! 👨‍💻✨

Aquí estarán alojados todos los laboratorios, prácticas y ejercicios desarrollados para la materia de **Arquitectura N-Capas**.  
El objetivo de este espacio es llevar un seguimiento organizado del aprendizaje y desarrollo de aplicaciones utilizando tecnologías modernas del ecosistema Java ☕.

---

## 📚 ¿Qué encontrarás en este repositorio?

En este repositorio se irán agregando diferentes laboratorios relacionados con temas como:

- 🏗️ Arquitectura en capas
- 🌐 Desarrollo de APIs REST
- 🛢️ Conexión y manejo de bases de datos
- 🔄 CRUDs completos
- 📦 Uso de DTOs y entidades
- ⚙️ Inyección de dependencias
- 🧩 Separación de responsabilidades
- 🔐 Manejo de validaciones y excepciones
- 🧪 Pruebas y buenas prácticas de desarrollo

Cada laboratorio estará organizado en carpetas independientes para facilitar su comprensión y ejecución 🚀.

---

## 🌱 Tecnologías utilizadas

Para el desarrollo de los laboratorios se está utilizando principalmente:

- ☕ **Java**
- 🍃 **Spring Boot**
- 🗄️ **JPA / Hibernate**
- 🛢️ **MySQL**
- 📬 **Postman** para pruebas de endpoints
- 🧰 **Maven** como gestor de dependencias
